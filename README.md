# Cartão Digital — Motorista Welmington

Cartão digital interativo em HTML, pronto para publicação no GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo `index.html` para o repositório.
3. Vá em **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

O cartão já é autocontido: as imagens estão incorporadas no próprio HTML.
